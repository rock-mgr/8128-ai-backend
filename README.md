# 8128-ai-backend
AI Backend

1. Execute `npm init -y` in the terminal of a new folder
2. The folder with the `package.json` file is the root folder or project root.
3. We have to install : `npm install express cors axios dotenv`
4. Install `npm install -g nodemon` to get Node monitor
5. `npm install @google/genai`
6. `npm install-scripts approve -a`
7.  Afterwards, run `npm install @google/genai` and `npm rebuild`
